# 独立检索实验 v2

创建日期：2026-10-18。材料在第一次跑新实验前冻结，见 freeze.json 中的 SHA-256。这里的制度全部是模拟数据。

- base_chunks.json：复制原来的七个片段，保留原 ID，原文件未修改。
- additional_policies.json：七份新增模拟制度，每份三个章节；复用学习者的章节切分函数，合计 28 个片段。
- dev_cases.json：30 条公开题，五类各六条，含必要证据、答案要点和业务家族。
- reserved_cases.json：10 条预留题，尚不运行；与开发题共享业务事实，不是外部独立数据。
- freeze.json：上述四个文件的哈希与初始固定参数。

新增材料的初始参数为每路及 RRF 池六条候选、最终两条、RRF 常数 60；分词与 BM25 参数保持昨天版本。若以后修改材料或参数，必须记录新版本或实验配置，不能覆盖旧报告后声称仍是第一次评估。

基线运行器：`python -m scripts.retrieval_lab --build` 构建独立文档索引；`python -m scripts.retrieval_lab` 运行开发题；`--case ID` 只检查某道开发题。不提供默认运行预留题的入口。模型均来自已有本地 Embedding，不调用聊天 API。

实验缓存与主索引是不同文件，旧问答数据库不变。这个实验先隔离比较排序策略；数据扩展、数据库版本更新等工程步骤另课处理。

问题类别与局限：边界题在这里仅验必要条款是否召回，不能证明模型做对数值比较；多题可能共享同一条款，不把案例数当作独立业务覆盖数；required_ids 是必要证据清单，不是全部相关片段标注。
