# Course-authoring workflow

Keep the Day1–26 sequence. Lessons, tasks and hints are rendered in the website;
README.md is the only Markdown entry at repository root. Put detailed guides in
docs/ or course/ and register useful browser resources.

projects/ and assignments/ belong to learners. Do not fill answers, fabricate
evidence, certify novelty from public variants, or mark completion from author
checks. Main starts unlearned; alexstudy preserves historical personal progress.
All resets must happen in an isolated release workspace, never in the learner's
active folder. Never copy .env, model weights or local databases into a release.
