# 小规模检索评测：从一个案例到可重复比较

前置：同一跨制度问题从 Top-2 调整为 Top-3 后找齐两份必要证据，真实回答及两份引用正确。本轮只比较检索，不调用 DeepSeek，不改默认检索参数。

## 助教提供与学习者实现

助教提供 data/retrieval_cases.json（12 条公开调试题及必要片段 ID）、scripts/check_retrieval_metrics.py 和 scripts/evaluate_retrieval.py。学习者只实现 app/retrieval_metrics.py 中 evaluate_evidence(retrieved_ids, required_ids)，不修改其他文件来通过验收。

题目有单条款、同制度跨条款、跨制度问题。它们是调试数据，并非独立保留测试集；本轮不声称生产效果。无答案问题的拒答后续单独评，不能以必要证据为空计为 100% 召回。所有 ID 对应当前版本的七个片段；制度更新后人工检查标注，不能静默跳过过期 ID。

## 函数契约

返回 evidence_recall（float）、all_required_found（bool）、missing_ids（去重并按字符串升序的列表）。召回率只计算不同的必要证据，命中无关片段和重复片段不加分；必要 ID 本身也去重。输入不能被修改。必要证据列表为空则抛 ValueError。

例如命中 ["remote", "other"]，必要证据 ["leave", "remote"]，返回：

```python
{"evidence_recall": 0.5, "all_required_found": False, "missing_ids": ["leave"]}
```

可以使用集合：set(列表) 去重，集合 & 集合求交集，集合 - 集合求差集，sorted(集合) 变成排序列表。len 返回数量；/ 返回浮点除法结果。实现用集合或普通循环均可。

## 两个指标

每题证据召回率 = 找到的必要证据数 / 全部必要证据数。

平均证据召回率 = 每题召回率相加 / 题目数。本轮每题权重相同，不是把所有题的证据汇总后相除。

全部证据命中率 = 找齐全部必要证据的题目数 / 题目数。

例如两道题都各需要两条证据：第一题找回两条，第二题找回一条，平均召回率为 (1.0 + 0.5) / 2 = 75%，全部证据命中率为 1 / 2 = 50%。部分召回不能当作完整可答。

平均正文字符数只表示候选正文规模，不等于 Token 数、模型账单或无关内容比例。增大 K 会带入更多片段，但不能仅凭字符更多就认定回答更差；需要生成评测验证。对同一排序取更长前缀，召回不会下降，因此不能仅靠最大召回选 K。

## 执行

```powershell
.\.venv\Scripts\python.exe -X utf8 -m scripts.check_retrieval_metrics
.\.venv\Scripts\python.exe -X utf8 -m scripts.evaluate_retrieval
```

先通过第一条，再运行第二条。评测一次加载索引和本地模型，每题只编码一次问题，同一排序比较 K=1/2/3/4，不重新编码文档。标注只参与计分，不进入问题编码。报告保留数据版本、指纹、索引清单、命中排序、各 K 缺失 ID 及汇总结果。
