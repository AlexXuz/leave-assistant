# Day18 · 独立交付：Agent 调用轨迹、故障恢复与成本延迟评估

## 交付目标与起点

为本人 Python 服务补齐模型/工具执行轨迹，实际注入故障并从业务状态决定恢复动作。再对一组冻结任务做同条件延迟与用量对照，为 Day20 的 Agent 效果评测准备数据。

沿用 `course/projects/failure_recovery_diagnostics.py`，保留已有函数和自己的实现；原 `course/assignments/failure_classification.py` 只是热身。可使用 Day16/17 本人服务，也可先复用已验收业务接口，不能调用作者诊断演示冒充本人采集链。

## 输入输出与实现边界

`summarize_trace(events)` 按 run_id/request_id 关联阶段和业务状态，至少返回阶段耗时、business_committed（true/false/unknown）及恢复建议。原 TraceEvent 是最小类型，可在自己的模块扩展 AgentTraceEvent，不必修改旧答案或通用契约。

每次模型/工具步骤至少记录 step_id、parent_step_id、phase、duration_ms、outcome、tool_call_id、脱敏参数概要、error_code、attempt、版本、usage 或 null。总耗时来自任务起止，不能把并行步骤耗时相加当端到端耗时。安全事件包含实际被拒绝动作与规则版本，不记录凭证、完整聊天或完整个人数据。

`compare_runs(baseline, candidate)` 使用相同冻结任务/环境比较成功与失败、p50/p95、已知token和缺usage数量。自行记录分位数算法、样本数、并发、预热、模型/Prompt/工具版本、价格口径及日期。存在缺usage时总费用标 unknown/null；估算值须另列，不能将缺失替换成0。

轨迹可用于重新评分和解释，不得默认重执行业务写工具。恢复动作必须查权威业务状态，已完成时读回原结果，无法确定时保持 unknown；重放旧确认或替换幂等key都不是排障捷径。

## 公开变体练习

1. 两次模型调用只有一次返回 usage，保留已知量与缺失计数，不给出伪精确的完整费用。
2. 两个工具并行结束，模型说明超时；总延迟须按真实任务时钟统计，恢复只能读回已完成动作。
3. 不可信工具文本要求扩大权限，记录实际拒绝事件和后续执行，不能只检查最终答案措辞。

公开变体不是秘密测试。依[证据规则](../EVIDENCE_PROTOCOL.md)冻结基线、领取挑战；已练过的条件由复核者换成新要求。

## 失败、边界与恢复

在隔离环境实际注入“写入已提交、响应丢失”或“工具成功、最终解释超时”，保留原失败和业务编号，再以同一业务标识核对并恢复。不能关闭无关服务或重置已有学习数据。另测无法确认业务结果，系统须停在 unknown 而不是猜测未提交。

确定性替身负责稳定复现错误路径；本机 HTTP 服务负责验证跨请求追踪；真实模型调用用于记录实际网络耗时和usage。三者分别标明，模型不可达不能计为语义答错，也不能被悄悄剔除。

## 验收标准

- **D18-C1**：本人轨迹能关联HTTP、任务、模型、工具和业务编号，按权威状态区分未执行、已执行和未知结果并解释恢复动作。
- **D18-C2**：提供冻结任务、重复安排、逐请求数据和同条件延迟/用量对照，缺usage与估算费用明确区分，失败样本保留。
- **D18-C3**：实际故障恢复不产生重复副作用，轨迹重放与工具重执行边界明确，旧确认不会被调试入口绕过。
- **D18-C4**：脱敏参数、版本、错误和安全事件足以排障且不泄密，替身/本机HTTP/真实模型证据来源准确。

关键项不能用总分抵消。一次正常回答或只测GET /api/me不代表本任务通过，也不能宣称生产SLA。

## 操作与交付

先写事件字段、记录范围、保留期限和判定预期，再改采集适配器。冻结基线后只改一个影响延迟/用量的因素，重复质量敏感案例，保留逐任务结果与原始失败。

正常、公开变体、失败恢复分别存本人产物，包含环境、任务/请求编号、预期、实际、业务状态、恢复动作和限制。填写 `course/submissions/failure_recovery_diagnostics.json`，格式遵循 [EVIDENCE_PROTOCOL](../EVIDENCE_PROTOCOL.md)。页面只检查结构/哈希，真实恢复和数据语义仍须复核。

分级提示沿用 [故障分类](../solutions/failure_classification.md)；先判断可信业务事实，再检查模型/工具轨迹，最后设计恢复与对照，不从异常名字猜结果。
