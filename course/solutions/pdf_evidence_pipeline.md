# Day8 · 分级提示与验收讨论

先独立尝试，不在这里提供完整接线答案。

## 提示一：明确输入输出

ingest_document(path, profile, services)保留页面结构和定位；cite_authorized_sources(source_ids, hits)按回答顺序去重映射，仅允许本轮命中的ID。空文本/损坏/扫描件转明确失败或后续OCR流程。

## 提示二：逐层观察

PDF文件/指纹 → 按页文本 → 保留定位的片段 → 授权检索 → sources校验 → 页码/范围引用。

指出每一层的对象类型、可信来源和失败语义，不把模型文本当业务事实。

## 提示三：从失败反推缺口

中间页无法解析时停止整次入库，不发布部分快照；修复文件后重跑，旧已发布来源仍可读。

- **D8-C1**：正文与页码/范围/指纹能对照原文。
- **D8-C2**：未知引用或未授权命中拒绝，不通过全库兜底。
- **D8-C3**：解析失败不当空文档，不触发错误删除。
