# Day4 · 分级提示与验收讨论

先独立尝试，不在这里提供完整接线答案。

## 提示一：明确输入输出

prepare_corpus(documents, embedder)保留片段顺序、ID、原文与向量对应；retrieve_context(question, corpus, embedder, top_k)只编码问题并取已建索引，不在每次查询时重建全库。

## 提示二：逐层观察

文档 → 带ID/版本的片段 → 离线文档向量 → 问题向量 → 排序 → TopK完整证据 → 消息。

指出每一层的对象类型、可信来源和失败语义，不把模型文本当业务事实。

## 提示三：从失败反推缺口

构造向量行数/维度与片段不一致的索引，明确拒绝；重新构建一致索引后恢复，不能默默错配。

- **D4-C1**：排序分数与片段一一对应，原文/元数据完整。
- **D4-C2**：查询只编码问题，索引与模型配置可追溯。
- **D4-C3**：区分候选缺失、排序问题和生成错误，检查输入不被修改。
