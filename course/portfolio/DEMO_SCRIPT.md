# Python Agent产品演示脚本

1. 0:00–0:40：说明目标、Python服务入口、合成/真实数据边界和可信身份。
2. 0:40–2:00：从自然语言启动客服调查，展示模型根据工具观察选择下一步、证据来源与最终回答；可追加一个缺信息追问。
3. 2:00–3:00：展示真实模型评测中的一次失败，沿task/request/tool-call定位，并用同任务对照修改前后结果。
4. 3:00–4:00：展示新领域任务，解释更换的数据源、工具和成功标准；已有轨迹可辅助，但明确哪些是录制回放。
5. 4:00–5:00：展示独立部署、worker恢复与业务读回，说明外部已成功而检查点未存时为何不会重复动作。

五分钟是概览，关键现场恢复与未见需求复核另留足够时间。准备commit、镜像/环境、逐trial报告和人工判定，不用清库制造成功；不要把模型文字或评测live标签代替实际调用证据。
