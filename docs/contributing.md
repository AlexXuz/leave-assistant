# 贡献指南

优先欢迎可以核验的课程改进：讲解错误、输入输出不清、真实失败案例、安装/跨平台问题、权限/恢复缺陷和可重复评测。

## 提交前

1. 从main创建自己的工作分支，保留默认骨架。学习答案留在个人分支，不直接覆盖公共练习。
2. 说明问题、受影响课程、复现步骤、预期与实际结果；使用合成数据。
3. 基础设施/参考实现的修复应有针对性回归。参考修复与学生答案不同，PR描述中说明变更范围。
4. 运行README中的相应检查。需要数据库/模型/额外依赖的部分如实写未执行，不伪造通过。
5. 不提交.env、Key、Cookie、模型权重、虚拟环境、真实员工资料和未经审阅的日志。

## 课程设计约定

职责命名使用snake_case。每课提供可直接打开的Python文件、输入输出、失败边界与独立验收。基础设施可以提供，核心新能力需学员实现；通过热身不代表完成课程。公开变体不能标成秘密未见集。

修改课程映射时同步网页、提示、依赖、验证说明与进度模板。保持Day1–26主线顺序，扩展方向放到明确的选修路径。不得在课程中假装已经完成生产、云部署或模型效果验证。

请用具体证据讨论技术取舍，尊重不同后端背景和学习节奏。漏洞和敏感信息处理见安全说明。
