# 安全与数据说明

本项目用于教学，资料、员工和业务额度均为模拟案例。默认账号/密码只用于本机回环地址；不要直接公开到公网。课程内容不是生产认证、权限、审批或HR系统的完整实现。

## 报告问题

公开Issue只放脱敏复现与合成输入。不要发布Key、会话、真实员工资料、内部制度或可以直接利用的敏感细节；需要私下沟通时，先只描述联系需求，等待维护者确认渠道。

发现凭证暴露时先在对应服务撤销/轮换，再处理仓库历史；删除工作区文件不能让旧凭证失效。本仓库不要求上传凭证证明问题。

## 运行边界

- 模型输出不能扩大工具、来源、部门或SQL权限。
- 明确确认、版本、幂等和事务由服务端强制，不能靠Prompt承诺。
- 任意代码、浏览器写操作和外部系统接入需要额外隔离/确认设计。
- 开发环境、参考示范和学员未完成实现不应直接作为生产服务发布。

生产补强与攻击评估见网页中的求职补强与安全评估资料。
